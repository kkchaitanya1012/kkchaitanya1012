## What I've built

| Project | What it does | Stack |
|---|---|---|
| [**vAna**](https://github.com/kkchaitanya1012/vAna) | Open-source voice session analytics. Shows where each turn of a voice call spends its time (hearing, thinking, voicing, delivery) and compares stacks by speed and cost. | Pipecat, FastAPI, Next.js, WebRTC |
| [**mapa**](https://github.com/kkchaitanya1012/mapa-cc) | An AI voice agent that phones a parent at medicine time, asks whether they took it and how they feel, in English or Telugu, and reports back to the caretaker. | Flutter, FastAPI, LiveKit, Sarvam, Supabase |
| [**persona-regen**](https://github.com/kkchaitanya1012/persona-regen-tool) | Measures how an agent's behavior changes when you swap its model, then rewrites only the prompt sections the gaps justify. | Python, OpenRouter |
| [**tribe-predict**](https://tribe-predict.chaitanyakalluri.tech/) | Predicts brain-network response to a headline, ad or email and suggests rewrites. Built on Meta's TRIBE v2. | React, FastAPI, Modal |

Each one has a case study with the product decisions behind it on [my portfolio](https://chaitanyakalluri.tech/#projects).
